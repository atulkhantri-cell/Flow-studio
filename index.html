What runs locally, and what it costs

Included at no charge

Unlimited local generations, all editing tools, character library, timeline, export, project backup. Files you create are yours, at native resolution, with no watermark.

Real costs you do pay

GPU hardware and its electricity, storage for model weights and renders (video models are tens of GB), and your time while frames render. Optional cloud compute is opt-in and never enabled silently.

Never

No hidden paid API calls, no credit counters, no simulated generations, no placeholder clips dressed up as output. If a model can't do something, the UI does not offer it.

Consistency guidance

Consistency is a property of the model, not of this interface. Reference-conditioned models (for example IP-Adapter-style conditioning or native reference support) hold identity far better than prompt-only workflows.

Use 3–8 reference photos with varied angles and consistent wardrobe. Keep the descriptor block identical across scenes. Expect drift in long sequences; re-anchor with a first frame taken from the previous shot's final frame.

Installation

# 1. Create the environment
python -m venv .venv
.venv\Scripts\activate        # Windows
source .venv/bin/activate     # Linux / macOS

# 2. Backend + ComfyUI bridge
pip install -r requirements.txt

# 3. ComfyUI (recommended local engine)
git clone https://github.com/comfyanonymous/ComfyUI
cd ComfyUI && pip install -r requirements.txt
python main.py --listen 127.0.0.1 --port 8188

# 4. Download weights (example, huggingface-cli)
pip install -U "huggingface_hub[cli]"
huggingface-cli download stabilityai/stable-diffusion-xl-base-1.0 \
  --local-dir models/checkpoints/sdxl-base

# 5. Start Flow Studio backend
uvicorn server:app --host 127.0.0.1 --port 8000
Weights are large (image models ~2–7 GB, video models commonly 20–60 GB+). Plan disk space accordingly.
